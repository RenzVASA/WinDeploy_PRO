# WinDeploy Pro

Prépare un PC Windows 11 neuf en un clic.

**[Ouvrir le générateur](https://renzvasa.github.io/WinDeploy_PRO/)**

Installer Windows, c'est rapide. Tout régler ensuite (veille, icônes, extensions de fichiers, applications…) prend une heure à chaque fois. WinDeploy Pro fait ça à ta place :

1. **Configuration** : tu choisis les réglages système (plan d'alimentation, mise en veille, hibernation, icônes du bureau, extensions de fichiers visibles, fond d'écran, dossier de journaux…).
2. **Applications** : tu coches les logiciels à installer.
3. **Génération** : l'outil écrit le script `.bat` correspondant, prêt à lancer sur le PC à préparer.

## Les fichiers

| Fichier | Rôle |
|---|---|
| `WinDeploy_PRO.html` | Le générateur, à ouvrir dans un navigateur |
| `WinDeploy_FREE.bat` | Une version prête à l'emploi avec les réglages de base |
| `WinDeploy_BETA.bat` | La version de test des nouvelles options |

## Utiliser un script

Clic droit sur le fichier `.bat`, puis **Exécuter en tant qu'administrateur**. Lis toujours un script avant de le lancer : il modifie des réglages système.
